## ⚡ Quick Start

1. **Clone the Repository**
   ```bash
   git clone [repository-url]
   cd sneakers-landing-page
   ```

2. **Launch Local Server**
   ```bash
   # Using Python
   python -m http.server 3000
   
   # OR using Node.js
   npx http-server -p 3000
   ```

3. **View the Project**
   - Open your browser
   - Visit `http://localhost:3000`
   - Start exploring! 🚀
